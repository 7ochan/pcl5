# pcl5

pcl5 contains a smart farming platform prototype in the `farming-platform` folder. The application is a Vite React MVP for farmers and vendors with dashboards, marketplace flows, mock data, and simulated AI recommendations.

## Getting Started

```bash
cd farming-platform
npm install
npm run dev
```

The development server typically opens on `http://localhost:5173`.

## Project Layout

```text
farming-platform/
  src/       React pages, context, components, and calculation utilities
  public/    Mock JSON datasets and Vite public assets
```

## Notes

- This repository keeps the application inside a subfolder.
- The app uses mock data for farmers, vendors, products, produce, weather, and base yield values.
- See `farming-platform/README.md` for detailed MVP behavior and limitations.
